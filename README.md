# English Zero → International Finance 🇬

Офлайн-приложение для изучения английского с нуля до уровня International Finance:
**5 модулей, 35 уроков, 1050 слов, 1800+ заданий, тесты и экзамены** — всё в одном HTML-файле.

🔗 **Демо:** откройте `index.html` прямо из репозитория (Download / Raw → сохранить → открыть в браузере)
или задеплойте на GitHub Pages за 1 минуту (инструкция ниже).

---

## ✨ Что умеет

- **Урок = 4 шага:** теория (правила, таблицы, примеры с озвучкой) → 30 слов (карточки, тест, ввод с клавиатуры) → практика (8–10 упражнений) → итоговый тест с разбором ошибок.
- **8 типов заданий:** раскрыть скобки, выбор варианта, перевод RU↔EN, порядок слов кликом, соответствие, верно/неверно, тексты с пропусками, свободное письмо с автопроверкой.
- **Интервальное повторение слов** (система Лайтнера: 1 → 3 → 7 → 16 → 35 дней) + ежедневная колода «на повторение».
- **Прогресс и мотивация:** проценты по урокам и модулям, серия дней, дневная цель, статистика точности.
- **Контрольные точки:** промежуточный тест (уроки 1–16), итоговый экзамен (1–30, открывает модуль 5), финальный тест Finance (31–35).
- **Справочник грамматики** со сквозным поиском по всем 181 правилу курса; поиск по словам и урокам.
- Озвучка примеров и слов (Web Speech API, акценты US/UK), тёмная тема, мобильная вёрстка, печать списков слов.
- **Работает без интернета.** Прогресс хранится локально в браузере; есть экспорт/импорт прогресса в файл.

## 📚 Программа курса

| Модуль | Уроки | Темы |
|---|---|---|
| 1. Фундамент | 1–8 | Present Simple/Continuous, Past Simple, Future, артикли, местоимения, исчисляемость, предлоги |
| 2. Грамматика+ | 9–16 | Present Perfect, Perfect vs Past, модальные, степени сравнения, порядок слов, there is/are, Past Continuous |
| 3. Business English | 17–24 | Числа и валюты, финансы, графики и тренды, Future Cont./Perfect, email, вежливость, Passive |
| 4. Intermediate | 25–30 | Conditionals 0–3, linking words, Reported Speech, фразовые глаголы, итоговое повторение |
| 5. International Finance | 31–35 | Financial statements, волатильность рынков, executive summaries, переговоры, макроэкономика и ЦБ |

## 🚀 Публикация на GitHub Pages (1 минута)

1. В этом репозитории: **Settings → Pages**.
2. В блоке *Build and deployment*: Source = **Deploy from a branch**, Branch = **main** (или master), папка = **/ (root)** → **Save**.
3. Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`.

Никакой сборки не нужно: `index.html` в корне — это уже готовое приложение.

## 💻 Разработка

Исходники лежат в папке `source/` (нужен Node.js ≥ 16, зависимости только для тестов):

```bash
cd source
node build.js ../index.html   # пересобрать приложение из данных курса
node build.js                 # собрать в ../dist/index.html и провалидировать данные
npm i jsdom --no-save         # (один раз) для UI-тестов
node test.js                  # интеграционные тесты всего UI
```

### Как добавить свой урок

Данные курса — это обычные JS-файлы в `source/data/` (по модулям). Добавьте объект урока
в нужный файл (или создайте новый) и пересоберите:

```js
__LESS.push({
  id: 36, mod: 'm5', minutes: 60,
  title: 'Название урока', short: 'Коротко для меню', subtitle: 'Описание',
  theory: [ { title: 'Блок теории', html: `<p>HTML-разметка правила…</p>` } ],
  vocab:  [ ['word','перевод','транскрипция','Example sentence.'], /* 30 строк */ ],
  exercises: [
    { title: 'Вставь форму', type: 'fill',  items: [ { q: 'She ___ (work) here.', a: 'works', why: '3-е лицо → -s' } ] },
    { title: 'Выбор',        type: 'mc',    items: [ { q: '…', options: ['a','b'], answer: 'a', why: '…' } ] },
    { title: 'Перевод',      type: 'tr',    items: [ { q: 'Я работаю.', a: ['I work'] } ] },
    { title: 'Порядок слов', type: 'wo',    items: [ { q: '…', a: ['I','work','here'] } ] },
    { title: 'Пары',         type: 'match', items: [ { pairs: [['work','работать']] } ] },
    { title: 'Верно?',       type: 'tf',    items: [ { q: '…', answer: true, why: '…' } ] },
    { title: 'Текст',        type: 'cloze', items: [ { text: '… [0] …', bank: ['work'], answers: ['work'] } ] },
    { title: 'Эссе',         type: 'write', items: [ { q: '…', kw: ['work'], min: 200, model: '…' } ] }
  ]
});
```

Сборщик (`node build.js`) автоматически проверит: 30+ слов в уроке, наличие ответов у каждого
задания, совпадение cloze-пропусков с банком слов и т.д.
